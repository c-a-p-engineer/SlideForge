# Codex への依頼例
変更点を 3 行で要約し、
影響範囲と未確認事項を分けて PR 本文を作成してください。

長い行は折り返し、シンタックスハイライトがなくても読めるようにする。強調は左の太線と余白で表現する。

AI

出力例

変更点: PR本文の章立てを統一し、確認手順を追加。

影響範囲: 文書生成フローのみ。実行コード変更なし。

未確認: スクリーンショット差し替えの要否。
