# Theme Catalog

SlideForge のテーマ説明一覧です。テーマは情報構造を変えず、見た目とトーンだけを切り替えるために使います。すべてのテーマは、デジタル庁デザインシステムの考え方を参考に、可読性、情報階層、余白、アクセシビリティを共通の前提にします。

現在同梱しているテーマは `book`、`light`、`dark`、`tech_news_catalog` です。いずれも 1920 x 1080 px の横型スライドを前提にしています。

各テーマは、IT解説・ニュース解説向けの同じ28種類のサンプルHTMLを持ちます。共通構造は `slides/sample-catalog.css`、色・トーンは各 `slides/<theme>/theme.css` で管理します。

ページごとの役割、使いどころ、生成済みプレビューは [sample-slide-catalog.md](./sample-slide-catalog.md) を参照してください。

## book

技術書・資料調のテーマです。白背景、明確な罫線、落ち着いた青アクセントを使い、印刷・PDF・長文寄りの説明に向いています。

向いている用途:

- 技術書風の補足資料
- 設計メモ、仕様整理、レビュー資料
- 表、コード、引用、時系列の堅めの説明

デザイン方針:

- 装飾を抑え、罫線と余白で情報階層を作る
- 本文は読みやすさを優先し、過度な光彩や背景装飾を使わない
- コードや表を資料として読める見た目に寄せる

## light

白から淡いグレーを基調にした標準テーマです。提案資料、社内説明、意思決定資料など、印刷・共有・レビューのどれにも使いやすい見た目です。

向いている用途:

- 提案資料、稟議、合意形成
- KPI 報告、ロードマップ
- 比較表、ガントチャート、問い合わせ先

デザイン方針:

- 背景は明るく、本文色は黒に近い色で読みやすくする
- 重要数値は青、導線や矢印は緑寄りのアクセントで分ける
- カードや説明ボックスは軽い境界線と控えめな影に留める

## dark

深い紺色ベースのテーマです。画面共有、動画素材、テック寄りの提案資料でコントラストを強く出したいときに使います。

向いている用途:

- 技術説明、サービス構成図
- 登壇資料、動画背景、画面共有
- フロー、システム図、コード、チャート

デザイン方針:

- 背景は深い紺色、文字は白寄りでコントラストを確保する
- セクションや構成図には薄いグリッドと光彩を使い、テック感を足す
- 水色を重要数値、緑を導線や処理フローに使い分ける

## tech_news_catalog

IT解説・技術資料・セキュリティ解説・ニュース動画向けのテーマです。
白背景カード、濃紺ヘッダー、青系アクセントを基本にし、ずんだもーしょん動画化時の下部字幕やキャラクター立ち絵と干渉しにくい余白を確保します。

向いている用途:

- IT解説、技術資料、セキュリティ解説
- インシデント解説、ニュース動画、論点整理
- API、DB、ログ、コード、リスク、時系列の説明

デザイン方針:

- 日本語の可読性を優先し、本文サイズと余白を大きめにする
- カード、表、コード、タイムライン、フロー、アーキテクチャ図を同じ見た目で扱う
- カタログ画像を背景として貼らず、再利用できるHTML/CSSテンプレートとして構成する
- 重要情報を最下部に寄せすぎず、動画字幕用の安全余白を残す

サンプル生成:

```bash
npm run generate:samples
npm run render -- --input slides/book --format png --preset widescreen
npm run render -- --input slides/dark --format png --preset widescreen
npm run render -- --input slides/light --format png --preset widescreen
npm run render -- --input slides/tech_news_catalog --format png --preset widescreen
```

## テーマ選択

- 迷ったら `light` を使います。
- プレゼン画面や動画で印象を強めたい場合は `dark` を使います。
- どのテーマでも slide type と情報構造は同じにします。テーマごとにページの意味や順序を変えないでください。
