# Sample Slide Catalog

IT解説・ニュース解説向けサンプル 28 枚の役割一覧です。

4テーマ（`book` / `dark` / `light` / `tech_news_catalog`）は同じページ番号・同じHTML構造を使い、色とトーンだけを各テーマの `theme.css` で切り替えます。GitHub Pages やリポジトリブラウザで確認しやすいように、生成済みPNGとコンタクトシートへのリンクも併記します。

## 再生成

サンプルHTMLを再生成する場合:

```bash
npm run generate:samples
```

PNG/PDFを再生成する場合:

```bash
npm run render:all
```

`dist/` 内の古い画像と新しい画像が混在すると確認しづらいため、必要に応じて再生成前に `dist/slides/<theme>/` や `dist/catalog/` を削除してください。
